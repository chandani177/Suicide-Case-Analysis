# Suicide-Case-Analysis
**Suicide Case Analysis** is a data analytics project that examines global suicide trends using a Kaggle dataset. The project includes data cleaning, preprocessing, exploratory data analysis (EDA), and interactive visualizations to identify patterns across countries, genders, age groups, and generations using Python, Pandas, Plotly, and Streamlit.
## Key Features

- Performed comprehensive data cleaning and preprocessing, including handling missing values, data formatting, and outlier detection to improve data quality.

- Conducted Exploratory Data Analysis (EDA) to uncover trends and relationships between suicide rates, demographics, and socioeconomic factors.

- Built interactive visualizations and dashboards using Plotly and Streamlit to enable dynamic exploration of global suicide statistics.

- Analyzed suicide patterns across countries, genders, age groups, generations, and time periods to generate meaningful insights from the data.
